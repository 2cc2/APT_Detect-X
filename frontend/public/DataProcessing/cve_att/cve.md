### 1. 远程代码执行 (RCE)

远程代码执行漏洞允许攻击者在目标系统上执行任意代码，通常通过发送特制的请求或数据包。

- **CVE-2014-6271** (Shellshock)
- **CVE-2017-12636** (Apache Solr)
- **CVE-2021-22205** (GitLab)
- **CVE-2021-44228** (Log4Shell)
- **CVE-2018-2894** (Oracle WebLogic Server)
- **CVE-2020-17519** (Apache Flink)
- **CVE-2021-29441** (Apache OFBiz)

### 2. 文件包含漏洞

文件包含漏洞允许攻击者通过包含恶意文件来执行代码或读取敏感信息。

- CVE-2019-6341(Drupal)

### 3. SQL 注入

SQL 注入漏洞允许攻击者通过注入恶意 SQL 语句来访问或修改数据库中的数据。

- CVE-2023-23752(Joomla!)

### 4. 拒绝服务 (DoS)

拒绝服务攻击通过耗尽目标系统的资源，使其无法正常提供服务。

- CVE-2020-11800(Apache Kylin)

### 5. 反序列化漏洞

反序列化漏洞允许攻击者通过发送特制的序列化数据来执行任意代码。

- CVE-2015-5254(Apache ActiveMQ)

### 6. 信息泄露

信息泄露漏洞允许攻击者访问未经授权的敏感信息。

- CVE-2016-9086(Jenkins)

### 7. 目录遍历

目录遍历漏洞允许攻击者访问服务器上的任意文件。

- CVE-2017-8046(Spring Framework)

### 8. 解析漏洞

解析漏洞允许攻击者通过特制的输入数据来触发意外的行为。

- **CVE-2019-0211** (Apache HTTP Server) - Apache HTTP Server 解析漏洞
